# ❤️ Heart Disease AI Predictor

Stacking Ensemble Machine Learning for Heart Disease Detection

## 🚀 Live Demo
Aplikasi ini di-deploy menggunakan Streamlit Cloud.

## 📊 Features
- Real-time heart disease prediction
- Interactive web interface
- Based on UCI Heart Disease Dataset

## 🛠️ Tech Stack
- Python
- Streamlit
- Scikit-learn
- SMOTE
